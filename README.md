#  Email Spam Detection using Bidirectional LSTM (BiLSTM)

##  Project Overview
This project is a Deep Learning-based Email Spam Detection system using Natural Language Processing (NLP) and a Bidirectional LSTM (BiLSTM) model.  
It classifies email/text messages as Spam or Ham with high accuracy.

---

##  Model Architecture
- Embedding Layer  
- Bidirectional LSTM (128 units)  
- Bidirectional LSTM (64 units)  
- Dropout Layers  
- Dense Layers  
- Sigmoid Activation Output Layer  

---

##  Features
- Text cleaning and preprocessing  
- Tokenization and padding  
- Label encoding  
- Exploratory Data Analysis (EDA)  
- Data visualization (word clouds, graphs)  
- Model training and evaluation  
- Confusion matrix and classification report  
- Real-time spam prediction  

---

##  Performance
- Accuracy: ~98%  
- Strong precision and recall for both Spam and Ham classes  
- Balanced and reliable model performance
